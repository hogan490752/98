# 素材来源与许可

房屋轮廓依据用户提供的图二及确认尺寸搭建。视频仅用于理解漫游、房间跳转和装修展示功能，没有采用视频中另一套房屋的尺寸或模型。

三维引擎使用 Three.js 0.186.1，MIT 许可。完整许可已保留在离线 HTML 中。

部分真实家具与材质来自 Poly Haven，按其 [CC0 许可](https://polyhaven.com/license) 使用。素材已嵌入交付文件，查看页面不需要向素材站请求资源。

制作工具为官方便携版 Blender 4.5.9 LTS，使用 Cycles 计算固定结构的间接光，使用 OpenImageDenoise 降噪。网页运行不需要安装 Blender。工具来源：<https://download.blender.org/release/Blender4.5/>。

## 固定点位全景素材

全景客厅使用 IKEA KIVIK 官方产品页所关联的三维预览模型，作为本户型个人装修参考，产品模型不在交付包中单独分发，也没有标为CC0。来源：[IKEA KIVIK](https://www.ikea.com/us/en/p/kivik-sofa-tibbleby-beige-gray-s39440593/)。网站材料的个人用途条款见[官方条款](https://www.ikea.com/us/en/customer-service/terms-conditions/)。

全景是根据本户型渲染的示意效果，未使用贝壳视频画面充当本户型全景。原视频仅作为视觉和交互参考。

本轮三套全景使用上述2K材质的颜色、法线和粗糙度图片。重力模拟床品、水槽盆腔、龙头、黑玻璃灶台、锅具及两卫马桶由本项目在Blender中制作。网页发布的是33张4096×2048渲染图，交付包不包含全景源场景或独立IKEA产品模型；保留的装修GLB对应原布局工作台。

14个比例假人由本项目的 `work/mannequins.py` 原创生成，未使用外部人物模型或真人照片。蓝灰色为1.70米站立身高，米色为1.60米；按统一成人示意体型制作，用于观察家具和通道的尺度。实时3D工作台使用同一生成器导出的原创GLB，嵌入 `work/realism-assets/mannequins.json`；不包含全景中的外部产品模型。
